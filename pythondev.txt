Two-Factor Authentication
 Login with email/password should not immediately return a JWT token.  The login endpoint should create a one-time verification challenge and trigger anemail.  For local validation, the latest email/code may be available through a development-onlyemail log endpoint.

 The verify endpoint should return the JWT token only when the correct code is supplied.  Codes must expire after 5 minutes, be single-use, and reject incorrect or reusedcodes.  If persisted, verification codes should not be stored in plain text.
